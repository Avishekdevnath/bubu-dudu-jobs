# bubu-dudu-jobs

Autonomous Recruitment Watchdog & Mobile PWA Portal tailored for **Avishek Devnath (Dudu, B.Sc CSE)** and **Chandrima Devnath (Bubu, B.Sc Agriculture)**.

## Features
- ⚡ **Pure Office Jobs Only**: Filtered strictly for executive, officer, and administrative roles (zero manual/trade posts).
- 👑 **Top Posts Filter**: 1-click filter for Class-1 / Grade 9+ officers (Assistant Director, Assistant Manager, Assistant Programmer, Assistant Maintenance Engineer).
- 🕒 **Urgency & Freshness Tracking**:
  - ✨ Just In (0–5 days)
  - 🚨 Urgent (≤ 3 days left to apply)
- 📲 **Installable PWA**: Works offline, installable on Android, iOS, Windows, and macOS.
- 🎯 **Direct Links**: Instant access to official Teletalk application portals and verified advertisement notices.
